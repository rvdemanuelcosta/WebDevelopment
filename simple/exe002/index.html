Testing lists

Ordened lists

To use ordened lists, use the tag ol to start a list, and use the tags li to create items.

Exemple:

  1. Banana
  2. Apple
  3. Orange
  4. Pineapple

they can be enumerated using the tag type, the options are:

  1. 1 for numbers
  2. a or A for letters
  3. I or i for romans numbers

Now lets see another way of creating lists, but without order of items.

Unordened lists

Unordened lists are made with the tags ul and the items are created with the li tag.

Exemple:

  • Wash dishes
  • Brush teeth
  • Ead
  • Sleep

Unordened lists uses simbles to mark the items with the parameter type in the ul tag, the available marks are:

  • disc
  • circle
  • square
